# EdTech CRM Funnel & Renewal Analytics (Business Analyst Case Study)

## Overview
An analytical and requirements case study examining **240 CRM lead and renewal records** across India and ANZ markets to identify conversion bottlenecks, SLA response delays, and renewal churn risks.

## What's Inside (`Bhumika_Singh_BA_Funnel_Renewal_Project.xlsx`)
- **Executive Dashboard:** KPI cards (Total Leads, Conversion Rate, Won Revenue, Eligible Renewal Rate, Avg First Response Time), channel & regional breakdowns, SLA bucket comparison (`<=2 hrs`, `2–12 hrs`, `>12 hrs`), and charts.
- **CRM_Funnel_Data:** Structured dataset tracking lead source, region, program tier, response hours, follow-up attempts, funnel stage, deal status, drop/churn reason, and renewal status.
- **BA_Case_Study_&_BRD:** Problem statement, key findings, functional requirements / user stories (`FR-01` to `FR-04`), and interview walkthrough notes.

## Key Business Recommendations
1. **Time-Zone SLA Routing (`FR-01`):** Route ANZ and inbound leads with response alerts so first-response time stays within SLA.
2. **Mandatory CRM Drop Reasons (`FR-02`):** Require structured drop/churn reasons on lost/churned records for accurate root-cause tracking.
3. **Lead Quality Verification (`FR-04`):** Add lightweight verification on high-volume paid social leads to reduce wasted calling effort.
4. **Earlier Renewal Triggers (`FR-03`):** Trigger proactive renewal outreach ahead of expiry, especially for shorter program cohorts.
